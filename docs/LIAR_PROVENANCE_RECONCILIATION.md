## 1. Executive Summary & Root Cause Resolution

An empirical provenance investigation was conducted to determine why the local dataset files (`research/fake-news-detection/`) report:
- **Local train:** 10,240 records
- **Local validation:** 1,284 records
- **Local test:** 1,267 records

While the canonical UCSB AI Group distribution (Wang, ACL 2017) documents:
- **Canonical train:** 10,269 records (difference: $-29$ records)
- **Canonical validation:** 1,284 records (difference: $0$ records)
- **Canonical test:** 1,283 records (difference: $-16$ records)

### Definitive Root Cause Finding:
**The original raw downloaded TSV files in `research/fake-news-detection/liar_dataset/` ARE 100% complete and contain all canonical lines (10,269 in train, 1,284 in valid, 1,283 in test).**

The discrepancy of 29 training records and 16 test records occurred entirely due to **CSV / TSV quote parsing behavior (`csv.QUOTE_MINIMAL` vs. `csv.QUOTE_NONE` / `quoting=3`)** when standard Python `pandas.read_csv()` parsed raw TSVs containing **unmatched double quotes inside political statements**.

Specifically:
1. In `train.tsv` and `test.tsv`, political statements containing unescaped quote characters (e.g., speech excerpts like `"Hospitals, doctors..."` without a closing quote on the same line) caused standard Pandas CSV parsers to treat subsequent newlines as multi-line string fields, inadvertently absorbing 29 training records and 16 test records into preceding statement columns.
2. In `valid.tsv`, the quotes balanced across lines or occurred without multiline absorption, resulting in the full 1,284 records being parsed.
3. The derived `train.csv` and `test.csv` generated by the upstream repository (`nishitpatel01/Fake_News_Detection`) persisted this standard Pandas parsing artifact.

## 3. ID-Level Analysis of the 45 Missing Records

When parsed with explicit quote disabling (`quoting=csv.QUOTE_NONE` / `quoting=3` in `pandas.read_csv`), the local TSV files yield **exactly the canonical counts**:
- `train.tsv`: Exactly **10,269 rows $\times$ 14 columns**
- `valid.tsv`: Exactly **1,284 rows $\times$ 14 columns**
- `test.tsv`: Exactly **1,283 rows $\times$ 14 columns**

### Mechanistic Proof of Parser Absorption:
In `train.tsv`, physical line 7,572 begins with:
```tsv
1720.json	false	"The vast majority of the money I got was from small donors all across the country.''	campaign-finance...
```
Notice the opening double-quote `"` followed by closing single-quotes `''`. Under standard RFC 4180 CSV parsing rules (`QUOTE_MINIMAL`), the parser expects a matching closing double-quote `"` and treats all subsequent lines—including line 7,577 (`10932.json`)—as internal multiline text of record `1720.json`.

## 5. Label Mapping & UI Terminology Guidance

The binary classification task groups the 6 fine-grained PolitiFact / LIAR labels as follows:

| Original Multi-Class Label | Binary Integer | Operational Grouping | Recommended Interface Terminology |
| :--- | :---: | :--- | :--- |
| `pants-fire` | `0` | Fake / Misleading | High Misinformation Lexical Framing |
| `false` | `0` | Fake / Misleading | High Misinformation Lexical Framing |
| `barely-true` | `0` | Fake / Misleading | High Misinformation Lexical Framing |
| `half-true` | `1` | True / Credible | Plausible / Credible Framing (Includes Nuanced Claims) |
| `mostly-true` | `1` | True / Credible | Consistent With Credible Lexical Distribution |
| `true` | `1` | True / Credible | Consistent With Credible Lexical Distribution |

### Critical Responsible AI Interface Recommendation:
Because `half-true` claims are mapped to class 1, the interface **must never describe class 1 as "Verified True Fact"**.  
NewsLens India already adheres to this rule:
1. Class 1 is labeled as **"Credible / Plausible Lexical Framing"** rather than "Verified Fact".
2. The UI explicitly discloses: *"A statistical screening score indicates stylistic phrasing patterns learned from the LIAR benchmark. It is not an empirical factual verification."*
3. Breaking news claims must always be corroborated with live Indian publisher RSS feeds and accredited watchdogs (PIB Fact Check, BOOM Live, Alt News).
